# Plans Directory Setup

**Date:** January 16, 2026
**Claude Code Version:** 2.1.9+

## Overview

This directory is configured to work with both:
1. **Claude Code's native `plansDirectory` setting** (v2.1.9+)
2. **planning-with-files plugin** (Manus-style planning)

## Configuration Applied

### 1. Settings (.claude/settings.json)
```json
{
  "plansDirectory": ".claude/plans"
}
```

This tells Claude Code to store plan files generated by native plan mode in `.claude/plans/` instead of the project root.

### 2. Git Ignore (.gitignore)
```gitignore
# Claude Code plans directory (session-specific, except README)
.claude/plans/*
!.claude/plans/README.md
```

Planning files are session-specific and should not be committed.

### 3. Directory Structure
```
.claude/plans/
├── README.md    # Documentation (tracked in git)
├── SETUP.md     # This file (tracked in git)
└── [planning files created during sessions - ignored by git]
```

## How Planning Files Work

### Native Claude Code Plan Mode
When you use plan mode or certain slash commands, Claude will create plan files here automatically:
- Files are stored in `.claude/plans/`
- Ignored by git (except docs)

### planning-with-files Plugin
The plugin still creates files in the **project root** by design:
- `task_plan.md` - Phase tracking
- `findings.md` - Research storage
- `progress.md` - Session logging

These are **also ignored** by git (see root .gitignore lines 66-68).

## Why Two Approaches?

**Native Plan Mode:**
- Automatic, built into Claude Code
- Stores files in organized directory
- Great for general planning

**planning-with-files Plugin:**
- Files live alongside your code in project root
- Follows Manus methodology explicitly
- Better for seeing planning files in file tree
- Templates and scripts included

## Usage

### Use Native Plan Mode
Just enable plan mode and Claude will use `.claude/plans/` automatically.

### Use planning-with-files Plugin
Run `/planning-with-files` skill - it will create files in your project root.

### Both Work Together
You can use both! They serve complementary purposes:
- Native for quick planning
- Plugin for structured Manus methodology

## Templates

The planning-with-files plugin provides templates at:
```
~/.claude/plugins/planning-with-files/skills/planning-with-files/templates/
├── task_plan.md
├── findings.md
└── progress.md
```

Copy these to your project root when starting complex tasks.

## Benefits

✅ **Organized:** Plans in dedicated directory, not cluttering root
✅ **Clean Git:** Session files never committed
✅ **Flexible:** Works with both native and plugin approaches
✅ **Documented:** README explains the system
✅ **Backward Compatible:** Existing planning files in root still work
