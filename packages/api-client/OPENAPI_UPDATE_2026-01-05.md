## Changes Made

### 1. Updated OpenAPI Spec
**File:** `src/api-v3/openapi-static.json`

**Tags Added:**
- `Jobs` - Async job management (imports, scans, enrichment)
- `Webhooks` - External webhook handlers

**Endpoints Added (14 total):**

- `POST /v3/jobs/imports` - Create CSV import job

- `GET /v3/jobs/imports/{jobId}/results` - Get import results

- `POST /v3/jobs/scans` - Create scan job

## Usage Example

```typescript
import { createBooksTrackClient } from '@jukasdrj/bookstrack-api-client'

const client = createBooksTrackClient({
  baseUrl: 'https://api.oooefam.net'
})

// Type-safe job creation
const formData = new FormData()
formData.append('file', csvFile)

const { data, error } = await client.POST('/v3/jobs/imports', {
  body: formData
})

if (error) {
  console.error('Job creation failed:', error)
  return
}

// Type-safe SSE streaming
const eventSource = new EventSource(
  `${data.data.streamUrl}?token=${data.data.token}`
)

eventSource.addEventListener('progress', (e) => {
  const update = JSON.parse(e.data)
  console.log(`Progress: ${update.progress * 100}%`)
})

// Type-safe status polling (fallback)
const { data: status } = await client.GET('/v3/jobs/imports/{jobId}', {
  params: { path: { jobId: data.data.jobId } }
})
```
